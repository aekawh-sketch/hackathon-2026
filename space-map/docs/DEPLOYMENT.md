## Запуск и настройки

Исходники веб-сервиса: `/opt/space-map/docker/space-map`.

```bash
cd /opt/space-map/docker/space-map
docker compose -f docker-compose.yml -f compose.production.yml ps
docker compose -f docker-compose.yml -f compose.production.yml logs --tail 100 api
docker compose -f docker-compose.yml -f compose.production.yml up -d --build
```

Актуальный код передан архивом Git, `.git` на VPS отсутствует. Для обновления сначала перенесите новый код из main, затем выполните сборку. Исходный commit записан в `/opt/space-map/docker/REVISION`.

Production-настройки лежат на VPS в `.env` и `compose.production.yml`. Пароли не хранятся в репозитории. Для администраторов — поле `ADMIN_EMAILS` с почтами уже зарегистрированных аккаунтов. После изменения окружения примените `up -d api` с обоими compose-файлами; `restart` не перечитывает `.env`.

Caddy на хосте сохраняет HTTPS-сертификаты и направляет запросы в Docker на `127.0.0.1:8000`. Порт 8000 недоступен извне; API и новая PostgreSQL не публикуют порты хоста. Cookies API имеют `Secure`. `/downloads/*` по-прежнему обслуживается из `/opt/space-map/public`, ссылки приложений сохранены.

Тома: `space-map_db` (PostgreSQL 18) и внешний `space-map_files` (панорамы и версии карт). Не удаляйте тома при обновлении. Docker и хостовый Caddy включены в автозапуск, контейнеры — `restart: unless-stopped`.
