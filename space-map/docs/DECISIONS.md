# Решения

Полный список — в `TZ.md`. Здесь — решения, принятые при реализации.

| Дата | Решение | Почему |
|---|---|---|
| 2026-10-23 | Монорепозиторий на npm workspaces: `packages/map-core`, `apps/web`, `services/api` | pnpm не установлен; npm хватает |
| 2026-10-23 | Импорты с расширением `.ts`, `allowImportingTsExtensions` | один и тот же код запускают Vite, Vitest, tsx и Node без сборки |

| 2026-10-23 | Метки на плане Konva рисуются в экранных координатах | толщина линий и размер иконок не зависят от зума |
| 2026-10-23 | Клик по пустому месту плана ловит Stage, а не контейнер | Konva шлёт click по `mouseup`, уже после `pointerup` контейнера |
| 2026-10-23 | 3D-модель строится из плана в `map-core` (`buildModel3D`), отрисовка и выгрузка `.glb` — three.js | внешние 3D-файлы не нужны; общие стены соседних помещений склеиваются, иначе мерцают |
