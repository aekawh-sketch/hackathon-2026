## Запуск

```bash
cd space-map
npm install
./tools/fetch-demo-panoramas.sh   # один раз; уже лежат в репозитории

# база (один раз): createdb spacemap && createdb spacemap_test
cp services/api/.env.example services/api/.env   # и задать DEMO_PASSWORD
npm run seed -w services/api      # миграции + демо-организатор + опубликованная площадка demo
npm run dev:api                   # http://localhost:8080 , OpenAPI — /api/docs
npm run dev:web                   # http://localhost:5173/m/demo , кабинет — /app ; с телефона — http://<IP-мака>:5173/…
```

Тесты API: `npm test -w services/api` (нужна база `spacemap_test`, она пересоздаётся при каждом запуске).

QR-якорь: `http://localhost:5173/m/demo?a=ENTRANCE` — точка «откуда» уже стоит у входа.

Редактор демо-площадки: `http://localhost:5173/app/editor` (кнопка с карандашом в шапке карты). Правки сохраняются в браузере и сразу видны на `/m/demo`; «Сбросить демо» в меню возвращает исходную площадку.

## Известные ограничения

- `heading` демо-панорам условный (0°): снимки Poly Haven не с нашего плана, метки в них стоят по расчёту, а не по реальным объектам.
- `react-router@8.5` просит Node ≥ 22.22, локально 22.21 — только предупреждение npm, в браузере не влияет.
