# Карта пространства — приложение для компьютера

Тот же сайт в отдельном окне (Electron): «Все карты», кабинет организатора, редактор, 3D. Окно запоминает размер
и положение, внешние ссылки открываются в браузере, камера разрешена только своему сайту (сканер QR-кода проекта).

## Сервер

Меню **Файл → Сервер**:

- **Стенд команды** — https://193-233-88-64.sslip.io (по умолчанию);
- **Локальный сервер (Docker)** — http://localhost:8000, сначала `docker compose up -d --build` в `space-map/`.

Любой другой адрес — переменной окружения при запуске: `SPACE_MAP_URL=https://… npm start`.

## Запуск и сборка

```bash
cd space-map/apps/desktop
npm install
npm start              # окно с сайтом
npm run dist:mac       # dist/space-map-<версия>-mac-<arch>.dmg и .zip
npm run dist:win       # установщик Windows (NSIS)
npm run dist:linux     # AppImage
```

Сборки не подписаны сертификатом разработчика. На macOS при первом запуске: правой кнопкой по приложению →
«Открыть» → «Открыть». На Windows SmartScreen: «Подробнее» → «Выполнить в любом случае».

Пакет отдельный от остального проекта (свой `package.json` и `package-lock.json`): Electron не скачивается при
`npm install` в `space-map/` и при сборке сервера.
