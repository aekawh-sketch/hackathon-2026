# Приложение для Android

Сайт «Карты пространства» в WebView — тот же кабинет и карта, что в браузере, — плюс встроенная съёмка фотосферы.

- `app/` — `MainActivity` (WebView со стендом, камера для разметки «по шагам», выбор файлов) и `CaptureActivity` (экран съёмки).
- `photosphere/` — съёмка и склейка из [360-photo-app](https://github.com/n30dyn4m1c/360-photo-app) (MIT, см. `photosphere/LICENSE`):
  точки на сфере, автоснимок, когда телефон замер, поворот по гироскопу (белые стены и ARCore не нужны),
  склейка с уточнением по общим точкам и мягкими швами. Своё: перевод строк на русский, подключение как библиотеки
  и кнопка «Пересчитать свет» (см. ниже).

## Экспозиция и баланс белого

В начале съёмки камера подбирает экспозицию и баланс белого, а когда они сошлись (или через 6 с),
модуль фиксирует их (`CONTROL_AE_LOCK`, `CONTROL_AWB_LOCK`) на всю сферу — иначе на швах были бы полосы
разной яркости и цвета. Перешли в другой свет (из комнаты в коридор с лампами) — кнопка «Пересчитать свет»
снимает блокировку, ждёт, пока камера сойдётся на новой сцене (первые 0,8 с отчёту «сошлось» не верим),
и фиксирует новые значения. Пока подбирается, кадры не снимаются.

## Как сайт снимает фотосферу

1. Страница (`apps/web/src/capture/native.ts`) вызывает `SpaceMapAndroid.capturePhotoSphere(id)`.
2. Приложение открывает `CaptureActivity`; готовую сферу (JPEG 2:1) отдаёт странице по адресу `/__native/sphere/<id>.jpg`
   на её же домене и вызывает `window.__spaceMapNative(id, { url, width, height })` (или `{ cancelled, reason }`).
3. Страница забирает файл `fetch`-ем и загружает его на сервер своей сессией — панорама встаёт в точку съёмки.
   Направление панорамы задают в редакторе: «Открыть панораму» → «Повернуть по двери».

## Сборка

```bash
cd space-map/apps/android
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties   # путь к Android SDK
./gradlew :app:assembleDebug                                 # JDK 21 Gradle скачает сам
# APK: app/build/outputs/apk/debug/app-arm64-v8a-debug.apk
```

Другой стенд: `./gradlew :app:assembleDebug -PstartUrl=https://адрес/app`. Собирается только arm64-v8a — OpenCV под все процессоры весит ~120 МБ.

## Обновление из приложения

Качать APK вручную нужно один раз. Дальше приложение при заходе (не чаще раза в час) читает `/downloads/space-map.json`
на том же сервере, что и сайт, и, если там сборка новее, предлагает «Обновить». Скачивает APK, сверяет размер и SHA-256,
проверяет пакет, версию и ключ подписи и отдаёт файл системному установщику. Код — `AppUpdater.kt`, формат описания — `Release.kt`.

Выпустить новую версию:

```bash
# 1. app/build.gradle.kts: versionCode на 1 больше (и versionName)
./gradlew :app:testDebugUnitTest :app:assembleDebug
../../tools/publish-android.sh "Что нового" "Ещё пункт"     # стенд команды по SSH
STAND=local ../../tools/publish-android.sh "Что нового"       # локальный Vite: apps/web/public/downloads
```

Скрипт берёт версию из самого APK и откажется выкладывать, если APK подписан не ключом команды, собран под другой
адрес или его `versionCode` не больше выложенного. `MIN_VERSION=N` делает обновление обязательным для сборок ниже N.

**Подпись.** Все debug-сборки подписываются общим ключом `keystore/team-debug.keystore` — поэтому APK с любого
компьютера встаёт поверх установленного. Сборки до 0.2.0 подписаны личными ключами: их нужно один раз удалить
и поставить 0.2.0 заново. Если Play Защита остановит установку («разработчик незнаком») — «Подробнее» → «Всё равно установить».

### Локальный стенд форка по Wi-Fi

Телефон и компьютер подключены к одной сети, веб-сервер слушает `0.0.0.0:5173`:

```bash
./gradlew :photosphere:testDebugUnitTest :app:assembleDebug -PstartUrl=http://192.168.1.243:5173/app
adb install -r app/build/outputs/apk/debug/app-arm64-v8a-debug.apk
cp app/build/outputs/apk/debug/app-arm64-v8a-debug.apk ../web/public/downloads/space-map.apk
```

Замените IP на адрес своего компьютера. После изменения адреса APK нужно пересобрать. HTTP разрешён только в debug-сборке; release сохраняет запрет. На Android 17+ локальный стенд в debug запрашивает доступ к устройствам поблизости (`ACCESS_LOCAL_NETWORK`) до загрузки WebView. Разрешение требуется для подключения по Wi-Fi; камера запрашивается отдельно при съёмке.

Версия для локальной проверки — 0.1.2. Нативный мост и выдача снятой сферы работают только для origin стартового адреса: совпадают протокол, хост и порт. Съёмка через нативную камеру доступна с HTTP-стендом; браузерные WebXR и камера страницы по-прежнему требуют защищённого контекста.

Vite dev/preview отдаёт `/downloads/space-map.apk` как загрузку с MIME `application/vnd.android.package-archive`; без собранного файла возвращает 404. APK и `local.properties` не входят в Git. Для отдельного production-сервера раздачу файла и заголовки нужно настроить на нём.
