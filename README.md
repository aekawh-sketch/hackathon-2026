# hackathon-2026

Репозиторий команды на хакатоне.

**Проект:** «Карта пространства» (кейс ТТК) — сервис карт помещений с панорамами и маршрутами.
ТЗ — [space-map/TZ.md](space-map/TZ.md). Агенты читают его перед началом работы.
Контекст для агента — [AGENTS.md](AGENTS.md), текущее состояние — [space-map/docs/STATUS.md](space-map/docs/STATUS.md).

## Правила работы (люди и агенты)

- `main` — только рабочий код. Напрямую в `main` не пушим.
- Каждая задача делается в своей ветке: `<имя-или-агент>/<задача>`, например `anna/auth`, `agent-1/api`.
- Готовую ветку вливаем в `main` через Pull Request.
- Перед началом работы: `git pull origin main`, чтобы не ловить конфликты.
- Один агент или человек — одна ветка. Две сессии в одной ветке не работают.
